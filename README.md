# Kanki VPN (کانکی وی‌پی‌ان)

اپ اندروید (Kotlin + Jetpack Compose) با موتور AmneziaWG / WireGuard و اشتراک از پنل `kankipro.cafe`.

## ساخت روی گیت‌هاب (APK نهایی)

۱. توی مخزن: **Settings → Secrets and variables → Actions** دو مقدار بساز:
   - `KANKI_KEYSTORE` : فایل کلید امضا (`kanki-release.jks`) به‌صورت base64
   - `KANKI_KEY_PASS` : رمز همان کلید
۲. هر `push` یا زدن **Run workflow** در تب Actions، APK را می‌سازد.
۳. فایل نصبی را از بخش **Artifacts** همان اجرا (`KankiVPN-apk`) دانلود کن.

> فایل کلید (`*.jks`) و رمزها را هرگز داخل مخزن نگذار؛ `.gitignore` جلویش را می‌گیرد.

## اجرا روی اندروید استودیو

- نسخه‌ی جدید اندروید استودیو (Narwhal یا جدیدتر) و JDK 17.
- پوشه‌ی `kanki` را با **Open** باز کن و منتظر **Sync** بمان (اینترنت لازم است).
- اولین ساخت، فونت‌ها و نقشه‌ی کشورها را خودکار دانلود می‌کند (تسک `fetchAssets`).
  اگر دانلود نشد، برنامه با فونت و نقشه‌ی پیش‌فرض باز می‌شود و خطا نمی‌دهد.
- نسخه‌ی `release` روی کامپیوتر خودت بدون کلید، با کلید دیباگ امضا می‌شود (فقط برای تست).
- برای ساخت از ترمینال: یک بار `gradle wrapper --gradle-version 8.13` بزن تا `gradlew` ساخته شود (اندروید استودیو به آن نیازی ندارد).

## اتصال «مستقیم»

- بخش **تانل**: کانفیگ‌ها همان‌هایی‌اند که پنل می‌دهد (Endpoint ایرانی).
- بخش **مستقیم**: فقط AmneziaWG. همان کانفیگ برداشته می‌شود و فقط دامنه‌ی Endpoint عوض می‌شود:

| کشور    | دامنه‌ی مستقیم     |
|---------|--------------------|
| ترکیه   | `tr.kankipro.cafe` |
| آلمان   | `g.kankipro.cafe`  |
| فرانسه  | `fr.kankipro.cafe` |
| هلند    | `nl.kankipro.cafe` |

- هر سرور تازه که به پنل اضافه شود، کشورش از اسم (یا شناسه‌ی نود) تشخیص داده می‌شود و دامنه‌اش خودکار
  `کدکشور.kankipro.cafe` می‌شود. اگر کشور تازه‌ای در `flagTable` (فایل `Screens.kt`) نیست، یک خط به آن اضافه کن.
- منطقش در `AppState.kt` (توابع `augment` و `directHost`) است.

## ساختار کد

| فایل | کار |
|------|-----|
| `AppState.kt` | وضعیت و منطق برنامه (اتصال، انتخاب هوشمند، خروج) |
| `Screens.kt` | صفحه‌ها (خانه، سرورها، تست، تنظیمات) |
| `Ui.kt` | تم، فونت، آیکون‌ها و اجزای ظاهری |
| `SubscriptionApi.kt` | خواندن صفحه‌ی اشتراک و کانفیگ‌ها |
| `VpnEngine.kt` | ارتباط با موتور امنزیا |
| `Extras.kt` | نوتیفیکیشن، دکمه‌ی منوی کشویی، فهرست برنامه‌ها |

## Hysteria2 (از نسخه‌ی 1.6.0)

اگر سرور در پنل Hysteria2 داشته باشد، در برنامه کنار AmneziaWG و WireGuard گزینه‌ی **Hysteria2** هم می‌آید.

- هسته‌ی رسمی Hysteria (`libhysteria.so`) و tun2socks (`libhev-socks5-tunnel.so`) داخل مخزن نیستند؛
  هنگام ساخت روی گیت‌هاب در فایل `.github/workflows/build.yml` دانلود و ساخته می‌شوند.
- برنامه لینک `hysteria2://` را از پنل می‌گیرد، هسته را با یک پراکسی SOCKS5 محلی اجرا می‌کند و
  همه‌ی ترافیک را از VPN به آن می‌فرستد. آی‌پی خود سرور از مسیر VPN بیرون می‌ماند.
- DNS، MTU و «برنامه‌های مستثنی» برای Hysteria2 هم کار می‌کنند.
